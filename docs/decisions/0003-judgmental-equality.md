# 0003: Minimal judgmental equality

- **Status:** Accepted for Core v0.1
- **Date:** 2026-08-26

## Decision

Core v0.1 uses an intensional judgmental equality generated by structural
congruence, transparent unfolding, and the specified beta-style computation
rules for its primitive type formers.

It has no equality reflection and initially no judgmental eta rules.

## Reason

Judgmental equality is one of the most consequential parts of a dependent type
theory. Keeping it small makes checking, metatheory, auditing, and independent
reimplementation more tractable.

## Consequences

- Propositionally equal terms need not be interchangeable by conversion.
- Extensional principles must be expressed and audited explicitly.
- Adding an eta or new computation rule requires a foundational decision.
- Conversion performance will be addressed algorithmically without changing
  the accepted relation.
